# PGI — Plataforma de Gestión Institucional

Sistema para centralizar la información institucional de la Universidad
Anáhuac Querétaro, hoy dispersa en hojas de cálculo y archivos sueltos,
con acceso controlado por área.

Visión completa del producto: [`docs/vision-del-producto.md`](docs/vision-del-producto.md).

## Módulo piloto

El módulo piloto de PGI es **Fresales**, el sistema de coordinación de la
mesa directiva de FESAL. Su código vive fuera de este repositorio y está
desplegado en https://fesal-interno.pages.dev. Este repositorio contiene el
análisis (visión, entrevista, requisitos, casos de uso y prototipo).
